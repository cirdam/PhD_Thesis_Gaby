# Cosmic-ray chapter figures

Integrated into Chapter 2 on 30 October 2026. The PDF files are identical to the approved draft assets. Published artwork is reproduced unchanged; the Peters-cycle figure is an original schematic, not measured data.

| Chapter figure / files | Source and interpretation |
|---|---|
| 2.1 — `pdg_spectrum.pdf` | PDG Fig. 30.1, [original vector file](https://pdg.lbl.gov/2025/figures/cosmicray/figures/The_CR_plot.pdf). Artwork unchanged; GeV axis and E² weighting retained. Experimental compilation with low-energy spline fits as explained in the caption. |
| 2.2 — `longair_shock_acceleration.pdf` | Longair, *High Energy Astrophysics*, 3rd ed., Fig. 17.3, p. 570; PDF page 588. Four original panels show the moving shock, shock rest frame, upstream rest frame and downstream rest frame. Original v₁,v₂ are mapped to text u₁,u₂. © M. Longair 2011, Cambridge University Press. |
| 2.3 — `longair_stochastic_acceleration.pdf` | Longair, Fig. 17.1, p. 564; PDF page 582. Original head-on and following magnetic-mirror encounter diagrams. Original cloud speed V is mapped to text u. © M. Longair 2011, Cambridge University Press. |
| 2.4 — `longair_hillas.pdf` | Longair, Fig. 17.10, p. 582; PDF page 600, after Hillas (1984). Original vector artwork, axes, source labels and diagonal retained. The line represents an approximate 10²⁰ eV proton requirement at β≈1; the caption states the charge/speed scaling explicitly rather than repeating the source caption's ambiguous division by zβ. It is a source-size/field constraint, not an experimental source identification or a second-knee contour. © M. Longair 2011, Cambridge University Press. Underlying reference: A. M. Hillas, “The Origin of Ultra-High-Energy Cosmic Rays,” ARA&A 22, 425–444 (1984), [publisher record](https://www.annualreviews.org/content/journals/10.1146/annurev.aa.22.090184.002233). |
| 2.5 — `grupen_air_shower.pdf` | Grupen, *Astroparticle Physics*, 2nd ed., Fig. 7.4, p. 240; PDF page 254. Original schematic of electromagnetic, hadronic, muonic and neutrino cascade components. © Springer Nature Switzerland AG 2020. |
| 2.6 — `ulrich_heitler_em.pdf` | Ulrich, Engel and Unger, PRD 83, 054026 (2011), Fig. 3, using p. 3 of the [authors' arXiv PDF](https://arxiv.org/pdf/1010.4310). Original equal-splitting construction. The caption identifies λₑ=X₀ ln 2 and explains the retained level numbering. |
| 2.7 — `ulrich_heitler_hadronic.pdf` | Same paper, Fig. 4, arXiv PDF p. 4. Black charged-pion branches and blue neutral-pion branches are retained. Only a representative continuing branch is expanded. Muon production is explained in the text, not claimed to be shown. |
| 2.8 — `pdg_xmax.pdf` | PDG Fig. 30.8, [original vector file](https://pdg.lbl.gov/2025/figures/cosmicray/figures/Xmax_sigmaXmax_PDG_new.pdf). Artwork unchanged. Observations and interaction-model predictions are distinguished in the caption. |
| 2.9 — `peters_cycle.pdf` | Original computed illustration. Formula, arbitrary weights, charge ordering and break sharpness are disclosed in the caption. No measured data were generated, digitized or fitted. Nitrogen represents the CNO group. |

The supplied PDF editions are the assets used by the thesis. Figure credits and source locations are recorded above.
